# Production requirements for the SyncGuard FastAPI backend (CPU inference only).
#
# This is a deliberately pruned subset of requirements.txt (the full local dev
# environment freeze), containing only what backend/main.py and
# src/inference/predictor.py actually import, transitively, at runtime:
#   - FastAPI web server + file upload handling
#   - CPU-only PyTorch / torchaudio for the frozen audio+visual models
#   - MediaPipe for on-the-fly face/mouth landmark extraction
#   - PyAV for decoding uploaded video (audio-visual mode)
#   - soundfile for audio I/O
#   - PyYAML for the sync model's config file
#
# Deliberately excluded: Jupyter, pytest, matplotlib/seaborn, scikit-learn,
# librosa, numba, pandas, torchvision, CUDA wheels, and every other
# training/notebook/experiment-only package in requirements.txt. None of these
# are imported by the inference path (verified by tracing every import in
# backend/main.py -> src/inference/predictor.py -> src/models/**,
# src/preprocessing/**, src/features/**, src/config.py, and the lazy MediaPipe
# landmarker import in scripts/extract_celebdf_landmarks.py).
#
# PyTorch CPU wheels are not on the default PyPI index; the extra index below
# supplies them. Versions match requirements.txt exactly (torch 2.13.0,
# torchaudio 2.11.0 as pinned there) — only the local CUDA build tag
# ("+cu130") is dropped, since that build does not exist for CPU wheels.
